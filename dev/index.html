AlgebraCore

Bienvenido a la documentación de AlgebraCore.jl, un paquete diseñado para definir y operar con expresiones algebraicas simples, siguiendo principios idiomáticos de Julia como el múltiple despacho y la composición funcional.

Tipos

AlgebraCore.ScalarOp — Type
ScalarOp{T}

Estructura que representa un escalar algebraico tipado. Sirve como base para definir operaciones algebraicas con múltiples despacho.

source

Operaciones Aritméticas

Comparaciones

Base.:== — Function
==(a::ScalarOp{T1}, b::ScalarOp{T2}) where {T1, T2}

Comparación exacta entre dos ScalarOp. Solo compara los valores internos, no los tipos.

source
Base.isapprox — Function
isapprox(a::ScalarOp, b::ScalarOp; kwargs...)

Comparación aproximada entre dos ScalarOp, utilizando el valor interno value. Permite pasar tolerancias configurables.

source
Base.hash — Function
hash(a::ScalarOp, h::UInt)

Función hash requerida si se define ==, para uso en diccionarios y sets.

source

Tolerancia y control de errores

AlgebraCore.Tolerance.get_tolerance — Function
get_tolerance() -> Real

Obtiene la tolerancia global actual para las operaciones de comparación.

source
AlgebraCore.Tolerance.set_tolerance! — Function
set_tolerance!(tol::Real) -> Nothing

Establece la tolerancia global para las operaciones de comparación. El valor debe ser un número real.

source
AlgebraCore.Tolerance.with_tolerance — Function
with_tolerance(f::Function, tol::Real) -> Any

Ejecuta la función f con una tolerancia temporal tol. Restablece el valor original al finalizar, incluso si ocurre un error.
